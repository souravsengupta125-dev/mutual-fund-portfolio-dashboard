# Mutual Fund Portfolio Analytics Dashboard

An interactive mutual fund portfolio analytics dashboard built using Python, Pandas and Plotly Dash.

## Features

- Portfolio overview
- Current holdings
- Purchase and redemption tracking
- Fund-level XIRR
- Portfolio return analysis
- Asset allocation
- Market-cap allocation
- Fund health analysis
- Interactive filtering and sorting
- Portfolio performance visualization

## Technology

- Python
- Pandas
- NumPy
- Plotly
- Dash
- Excel / OpenPyXL

## Data

The project uses an anonymized sample mutual fund transaction dataset.

The sample data does not contain personal portfolio information.
